# 부산 도시철도 승하차 CI 샘플 데이터 (data/samples/subway/)

본 디렉터리는 GitHub Actions CI 및 단위 테스트 검증을 위해 공공데이터포털 부산교통공사 시간대별 승하차 데이터에서 추출한 초경량 샘플 CSV 파일들을 보관합니다.

## 1. 샘플 파일 구성

1. **`subway_2023_sample.csv` (CP949, 30개 컬럼, 20행)**
   - 2023년 6월 1일 ~ 6월 2일 (주 분석 시작 시점)
   - 주요 5개 역사(서면 119, 부산역 113, 사상 227, 광안 209, 다대포해수욕장 95)의 승하차 데이터
   - 컬럼: `역번호`, `역명`, `년월일`, `요일`, `구분`, `합계`, `01시-02시` ~ `24시-01시`

2. **`subway_2025_sample.csv` (UTF-8-SIG, 30개 컬럼, 10행)**
   - 2025년 1월 1일
   - UTF-8 BOM 인코딩 대응 및 최신 승하차 패턴 검증용

3. **`subway_duplicate_sample.csv` (CP949, 30개 컬럼, 6행)**
   - 2024년 7월 1일 서면역(119), 사상역(227)에 발생한 중복 오류 레코드(합계 26 vs 합계 수만 건) 포함
   - 중복 레코드 클렌징 및 정상치 보존 로직 단위 테스트용 엣지 케이스 샘플

## 2. 공공누리 제1유형 출처 표기
- **출처:** 공공데이터포털(data.go.kr) - 부산교통공사 시간대별 승하차인원
- **라이선스:** 공공누리 제1유형(출처표시, 상업적 이용 및 변형 가능)
- **개인정보:** 개인 식별 정보 없음 (역사별 집계 통계치만 수록)
